## 已实现入口

```sh
# 仅校验本机凭据、权限和字段格式
pnpm gate:feishu
# 只连接，不发消息；成功后退出
pnpm gate:feishu --connect
# 文本、卡片、持久化、重复按钮、过期按钮及重连
pnpm gate:feishu --live --timeout 900
# 单独验证消息事件在写库失败后是否自动重投；不发送消息
pnpm gate:feishu --retry-message --timeout 600
```

先停止其他使用同一应用的接收脚本，避免事件被分配给别的连接。用户已确认完成此操作，并配置 `card.action.trigger`。凭据从 `config/feishu.local.json` 读取；要求普通文件、当前用户所有、无其他用户权限，拒绝符号链接。错误、日志与报告不包含 Secret、访问令牌或回调 token。

`--live` 连接后显示本轮随机文本。只有应用、租户、用户 open_id、专用 chat_id、单聊类型全部匹配的真实消息落库后，才发测试文本和卡片。卡片操作绑定本轮 nonce、消息 ID、有效期与同一身份范围。用户按说明点击按钮，再发送重连测试文本。不会执行命令、接管 Codex 会话或安装后台服务。

## 证据与确认边界

每轮 `.artifacts/g1/<timestamp>-<runId>/` 保存：

- `report.json`：脱敏摘要、分项状态、SDK 文件摘要、耗时与清理结果。
- `events.jsonl`：脱敏事件身份 hash、处理结果与 SDK ACK 发送尝试。
- `probe.sqlite`：探针专用 inbox、测试命令、按钮 nonce 与发送意图。目录 700、文件 600，整体被忽略。

默认不保存原始事件正文。样本仅保留已消费字段的形状、身份匹配结果与事件 hash。每次发消息前先落发送意图；网络结果不明确时保留 unresolved，不自动重发。新一轮命令会创建新的测试轮次及消息，不用于补发旧轮次。

探针观察固定 SDK 的 `handleEventData` / `sendMessage` 调用边界，不修改安装包。SDK 成功码为 200；handler 抛错时生成 500。ACK 记录只证明 SDK 发起了发送，不能证明飞书服务器已经收到；卡片 toast 的客户端表现需要真实用户确认。耗时由本地单调时钟测量，覆盖处理到发送尝试，不是公网端到端延迟。

## 本地自动验证

15 个 G1 测试使用真实 SQLite 文件和已安装 SDK 的帧分发/响应代码，仅替换网络发送函数：

- 另一条只读数据库连接在 SDK 成功 ACK 之前可见 inbox 和命令。
- 同一事件重投、同一消息不同事件 ID、同一按钮不同点击，仅提交一次命令。
- 重开数据库后仍可去重；命令插入失败时 inbox 一起回滚。
- `query_only` 注入真实 SQLite 写失败：返回 500、零入站/命令提交，重投后一次提交。
- 应用、租户、用户、会话与非单聊越权拒绝；过期按钮、伪造 nonce、复制到其他消息的按钮拒绝。
- 缺少事件身份时拒绝成功确认；敏感字段不进入摘要。
- 凭据文件权限、符号链接、无效 JSON 的安全错误处理。

这些测试不计作真实平台重投或另一账号的越权联调。`pnpm verify` 已通过：7 个测试文件、50 个测试，以及类型检查、静态检查、格式检查和构建。`gate:feishu --help` 与默认配置校验也通过。

本轮 7 次 SDK ACK 发送尝试：6 次成功且已持久化、1 次预期故障 500；成功样本本地 P95 为 5.409 ms。最终 6 条 inbox、4 条测试命令。样本量很小，只是门禁测量，不代表长期性能承诺。自有连接与数据库已关闭。

消息自动重投使用独立 `--retry-message` 模式：仅对本轮准确测试文本首次注入写库失败，随后以相同事件 ID 的重投验证恢复，不把用户手动发送第二条消息当作通过。

补测轮次 `b86ae4b7` 已连接，等待 600 秒期间未收到约定测试文本，记录为 **BLOCKED（缺少测试输入）**，ACK 数量为 0；没有执行写库故障注入，也没有得到平台会/不会重投的结论。该轮连接与数据库均已关闭，旧测试文本现已失效。继续时重新运行 `pnpm gate:feishu --retry-message --timeout 600`，只发送新一轮显示的文本一次。

两轮共向用户指定的测试单聊发送 2 条文本和 1 张卡片，并更新该卡片一次；补测轮次没有发送消息。没有安装服务、修改 Codex 配置或执行模型任务。报告/日志已检查，不含实际凭据或账号标识；产物目录为 700、文件为 600。
