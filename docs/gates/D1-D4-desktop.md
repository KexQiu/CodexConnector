以下检查均通过：

- `pnpm lint`、`pnpm format:check`、`git diff --check`。
- `pnpm test`：28 个测试文件、339 项测试。包含现有网关回归与桌面新增测试。

- `hdiutil verify`：最终 DMG 完整性通过。

- 在源码之外、`PATH=/usr/bin:/bin` 下，随包后端 `initialize`、`status`、Codex 版本检查通过；父 IPC 断开后正常退出。
- 原部署只读核对：App Server 就绪、Gateway 就绪、飞书连接在线；根 `dist` 的构建摘要与部署清单一致。
