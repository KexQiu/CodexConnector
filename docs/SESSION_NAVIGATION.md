# 会话列表、完整回复与 ID 展示

2026-09-23 已部署，初版任务库 schema v8；当前随 [导航卡片升级](./NAVIGATION_CARDS.md) 使用 v9。本轮包含会话选择、正文阅读、按钮边框修复和原卡中的完整 ID 展示。

## 手机端使用

1. 在机器人单聊发送 `/当前`，点击“切换会话”；也可以直接发送 `/会话 m5fixture`。
2. 每页最多四个会话，同一 thread 的多轮任务合并为一项；展示话题标题、最近摘要、最近更新时间、轮次和执行状态，当前选择标记为“当前”。
3. 点击“切换到此会话”后直接发送后续需求。切换本身不创建任务，当前正在执行的会话仍按原规则排队。
4. 原会话列表和任务回复卡直接展示完整任务 ID；详情卡另外展示会话 ID，未建立会话时不编造 ID。按用户选择，仅保留 ID 展示，不提供复制按钮或跳转页。
5. 需要查询时可发送 `/状态 任务ID`；日常操作优先使用会话切换和详情按钮，无需输入 ID。`/继续`、`/打断` 也使用任务 ID；Codex 会话 ID 用于桌面定位，不能代替任务 ID。
6. 回答较长时点击“查看完整内容”，使用“上一页 / 下一页”阅读；短回答直接完整展示。

**本功能仅展示 ID，不写入手机剪贴板，也不依赖代码块复制图标。** 用户实测看不到该图标，原生复制方案未通过；用户随后选择“不跳转，保留 ID 展示即可”。新卡已移除“复制 ID”按钮及复制操作提示。任务 ID 直接出现在当前会话面板（已绑定任务时）、会话列表、任务回复及全文卡；会话 ID 出现在详情和桌面列表中。旧卡保留历史按钮行为，点击后仅展示 ID 信息，不表示复制成功；请重新发送 `/当前`、`/会话` 或刷新任务卡取得新版。

“桌面会话（只读）”显示标题、摘要、状态、时间和完整会话 ID；只查看，不接管桌面会话。也可使用 `/会话 项目key 页码 桌面`。桌面数据缺失时显示未命名或无可用摘要，不用其他会话的信息填充。

## 展示与行为

- 所有普通按钮只使用带边框的 `default`、`primary`、`danger`，包括刷新和切换项目；审批各决定保持相同视觉权重。
- 当前已选中的会话省去重复“接着聊”。新话题和切换项目集中在当前面板；回复卡直接展示任务 ID，并保留详情入口，按需要增加全文、刷新、停止等按钮。
- 正文从开头展示，不再只截取结尾。每页最多约 1,600 个 UTF-16 单元，优先沿换行分页且不截断代理对；分页拼接保留所有原始字符。
- 支持受控标题、列表、加粗、行内代码和代码块；模型生成的链接/HTML/提及不作为任意卡片组件解释。跨页代码段继续以代码展示。这里的“完整内容”指数据库当前保留的输出，不恢复已按留存策略清理的历史。
- 每项会话的切换按钮和任务 ID 代码块紧邻该项，翻页/桌面入口在底部。回复包含多个会话的列表卡时，明确要求先选择会话，不猜测目标。
- 导航、详情、全文和历史复制按钮使用事件 ID 去重：同一平台事件重复投递只处理一次，用户新的点击可重新读取。审批、控制和提交需求的幂等规则保持原有约束。
- 新回调仍核验用户、应用、租户、单聊、消息、任务归属和有效期。ID 展示不操作剪贴板，翻页不修改选中态；切换只更新本人的上下文。
- 已冻结的投递内容保留原样，标题中的完整回执继续用于未知发送结果核对。历史已发送卡片不会被批量重写；`/当前`、`/会话` 获取新版卡片，历史任务也可用 `/刷新 任务ID` 更新。

## 实现

- `session-cards.ts`：按项目和 owner 聚合 Gateway 会话、只读桌面列表、ID 卡和全文分页卡。
- `result-pages.ts`：保留字符的分页与允许的 Markdown 格式转换。
- `card-layout.ts`：统一带边框按钮、ID 代码块和与条目相邻的操作区。
- `commands.ts` / `inbound.ts` / `sender.ts`：列表入口、回调路由、可重复导航及状态对应的按钮。
- `008_session_navigation.sql`：扩展受约束的 `sessions`、`result`、`copy_id` 动作，保留旧动作记录和外键；新增动作不放宽执行授权。

依据：[飞书卡片交互](https://open.feishu.cn/document/feishu-cards/configuring-card-interactions)、[按钮类型](https://open.feishu.cn/document/feishu-cards/card-json-v2-components/interactive-components/button)、[Markdown 与代码块](https://open.feishu.cn/document/feishu-cards/card-json-v2-components/content-components/rich-text)。
