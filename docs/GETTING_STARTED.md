# 下载版安装与首次使用

适用版本：`0.2.0-alpha.2`，Rust/Tauri 宿主、过渡 Node 网关。

## 安装

需要 Apple Silicon Mac、macOS 13.5 或更高版本，以及已安装并登录的 Codex。App 自带 Node 和后端依赖，使用者无需安装 Node、pnpm、Rust 或下载源码。目前未提供 Intel 安装包。

1. 从 [GitHub Releases](https://github.com/KexQiu/CodexConnector/releases/tag/v0.2.0-alpha.2) 下载 `CodexConnector-Rust-0.2.0-alpha.2-arm64.dmg` 与 `SHA256SUMS`。
2. 可在下载目录运行 `shasum -a 256 -c SHA256SUMS --ignore-missing` 核对下载文件。未下载的附属文件可能被跳过，DMG 必须显示 `OK`。
3. 打开 DMG，将 **CodexConnector Rust.app** 拖入 **Applications**，再从“应用程序”打开。
4. 这是未做 Developer ID 签名和公证的预览版。如 macOS 阻止打开，先核对来源与校验和，按 [Apple 官方说明](https://support.apple.com/en-us/102445) 在 **系统设置 → 隐私与安全性 → 仍要打开** 处理。不要关闭 Gatekeeper 或系统保护。企业管理策略可能不允许打开未公证 App。

## 首次配置

打开 App 后默认停止，不会自动连接飞书。

1. **应用设置 → Codex 环境**：检测本机 Codex；必要时手动选择可执行文件。登录在 Codex 中完成。检查实际版本、核心协议与登录状态后应用设置。
2. **飞书连接**：选“连接已有机器人”，或试用“创建新机器人”。按 **接入机器人 → 完成飞书设置 → 绑定单聊 → 检查并保存** 完成。对应步骤有离线教程和手动填写备选方式。飞书后台需发布应用并使权限、消息事件和卡片回调生效。
3. 最后可“检查并保存”，也可“跳过检查，直接保存”。检查不发测试消息、不创建卡片；只核对凭据、单聊历史读取与长连接。跳过显示“未验证”，不会绕过正式启动的必需检查。
4. **本地项目**：添加已有独立目录，或使用自动发现的 Codex 项目。选择 **只读分析** 或 **允许修改项目文件**，按需开启联网；新项目默认 **禁止远程执行**。修改只缓存为草稿，停止服务后点击 **应用配置** 才生效。
5. 回到 **总览 → 启动连接**，等待飞书长连接在线与执行后端就绪。
6. 在专用机器人单聊发送 `/项目`，选择已经在本机授权的项目，然后直接描述任务，例如“说明这个项目的目录结构”。后续消息可继续同一会话。

飞书 `/当前` 查看选中项目、会话、模型、上下文和任务队列；`/会话` 切换会话；`/额度` 单独查看账号用量；`/帮助` 查看任务控制与其他命令。翻页和状态刷新优先更新原卡。具体权限边界见 [本机配置](./LOCAL_CONFIGURATION.md)。

本地项目可以暂时不填，但能否执行无项目普通聊天取决于独立能力检查。当前 `codex-cli 0.159.2` 可通过项目协议检查，**无项目聊天尚未通过该版本的 NP0 门禁**；这时请先配置授权项目。项目功能通过不代表所有 Codex 版本或工具能力均已验收。

## 停止、重开与数据

点击“停止连接”、关闭窗口或 `⌘Q` 会进入停止流程；有未完成任务时需确认。只停止 App 自己创建并验证归属的网关与 App Server，不关闭独立 Codex 桌面任务。未能确认结束的任务保留未知状态，不自动重复执行。App 不提供关闭后隐藏运行模式；登录项仅自动打开控制台，不自动连接飞书。

安装版数据位于 `~/Library/Application Support/CodexConnector Rust`。Secret 使用 Keychain 密钥加密；权限请求被拒绝时不会写明文替代。配置草稿、数据库、日志和备份留在本机。飞书消息与模型调用仍使用飞书和 Codex 的服务，项目不提供额外中转云服务。

原 Electron 数据在 `~/Library/Application Support/CodexConnector`，两份档案独立。当前 Rust 版本没有旧凭据或历史自动迁移，不要复制密文、混用数据库或同时连接同一个机器人。直接更新同一 Rust App 会沿用 Rust 数据；更新前建议停止服务并备份整个数据目录。

## 常见问题

| 现象                                     | 操作                                                                             |
| ---------------------------------------- | -------------------------------------------------------------------------------- |
| 启动按钮不可用                           | 查看按钮旁原因，完成 Codex/飞书配置，应用其他页面草稿                            |
| Codex 协议不兼容                         | 核对实际版本与差异；不要绕过检查。附脱敏诊断到 Issue                             |
| `app_server_unavailable` / socket 被占用 | 确认没有旧开发网关或重复 App Server；使用对应控制台停止，不按进程名称批量终止    |
| 项目目录不存在                           | 恢复目录，或本机关闭该项目远程执行后应用配置                                     |
| 项目包含网关数据目录                     | 选择独立项目，尤其不要授权开发模式下的整个源码目录为严格可写                     |
| 飞书已绑定却无任务结果                   | 核对应用发布、可见范围、消息事件、卡片回调及权限；基础连接检查不替代这些实际验证 |
| Keychain 拒绝访问                        | 在本机处理系统授权，再重试；不删除密钥或覆盖原凭据                               |

预览版实际验证和未覆盖项目见 [Rust 门禁记录](./gates/rust-desktop.md)。反馈时附版本、操作步骤与脱敏诊断，不上传 Secret 或私有历史。
