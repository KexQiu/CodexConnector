# CodexConnector 0.2.0-alpha.2

首个公开 Apple Silicon 预览版。通过飞书单聊连接本机已登录的 Codex，管理项目、连续会话与任务结果。

## 主要功能

- Rust/Tauri 桌面宿主，复用 React 界面及已实现的网关；安装者不需要 Node、pnpm 或源码。
- 飞书分步接入、已有机器人配置、绑定单聊、可跳过的基础检查，以及离线教程和草稿缓存。
- 本机项目自动发现、独立权限设置、并发配置和远程创建项目开关。
- 总览、日志与诊断、模型/上下文/额度卡片，以及原卡刷新和分页。
- 修复安装版图标缺失与启动错误无法定位；适配 Codex `0.159.2` 的非权限枚举扩展。
- MIT 开源，保留第三方许可，分发原始许可文本与必要源码归档。

## 安装

下载 `CodexConnector-Rust-0.2.0-alpha.2-arm64.dmg`，将 App 拖入“应用程序”。需要 **macOS 13+、Apple Silicon、已安装并登录的兼容 Codex**。具体步骤见 [安装指南](https://github.com/KexQiu/CodexConnector/blob/v0.2.0-alpha.2/docs/GETTING_STARTED.md)。

同时提供 `SHA256SUMS`、`release-metadata.json` 与 `THIRD_PARTY_NOTICES.txt`。元数据记录对应源提交和本轮校验结果，GitHub 的 Source code 文件提供 tag 对应源码。

## 当前限制

- **预览版，ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** macOS 可能阻止打开，请核对来源与校验和，再按 [Apple 官方说明](https://support.apple.com/en-us/102445) 处理。受管理设备可能不允许安装。
- 当前是 **Rust 宿主 + 过渡 Node 网关**，尚未迁移为全 Rust 后端；没有 Intel 包或自动更新。
- 项目协议已检查 `codex-cli 0.159.2`；无项目普通聊天对该版本暂不可用，独立 NP0 门禁未通过前不会开放。该能力仍只放行先前验证的精确二进制与策略。
- Rust 档案与 Electron 档案独立，没有旧凭据/历史自动导入。请保留旧档案，不要让两个网关同时连接同一机器人。
- 扫码入口仍为试用；新 Rust 宿主上的扫码、完整消息/卡片收发、运行任务中断、异常退出、登录项及新 Mac 安装环境仍需补充验收。

已完成 TypeScript 回归、Rust 检查、私有管道/加密/缓存/正常退出门禁、Codex 后端启动、真实安装版飞书长连接、实际图标与 React/IPC 冒烟，以及 DMG 挂载后在中文/空格目录启动。新产物会再次执行构建和安装冒烟；详细证据与未覆盖范围见 [验收记录](https://github.com/KexQiu/CodexConnector/blob/v0.2.0-alpha.2/docs/gates/rust-desktop.md)。
