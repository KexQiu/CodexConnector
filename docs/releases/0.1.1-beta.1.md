## 安装与回退

1. 保留旧版 App；退出正在运行的 CodexConnector，等待其服务停止。退出有任务时按提示处理，不强制结束进程。
2. 在 Finder 用“前往文件夹”打开 `~/Library/Application Support`，复制整个 `CodexConnector` 目录到单独的备份位置。数据备份只保留在本机。
3. 打开本版 DMG，将 App 拖到“应用程序”。更新内部包可能再次请求 Keychain 访问；本版使用 ad-hoc 签名，未做 Developer ID 签名公证。
4. 启动后核对侧栏版本为 `0.1.1-beta.1`、旧绑定与项目仍在；点击启动连接，再发送一条普通消息并确认回复。关闭、重开后再核对配置与历史。
5. 如需回退，先正常退出新版，再恢复旧 App。需要恢复配置时，将新版数据目录整体留存，再用升级前备份替换；不要合并两个数据库或在服务运行时覆盖数据。回退到备份会放弃升级后的新增历史，因此保留新版数据供后续核对。

## 可复现打包

在项目根目录执行 `pnpm desktop:release`。脚本使用版本号与 UTC 时间创建 `.artifacts/releases/<version>/<timestamp>`，在其中独立构建、暂存和打包，保留常规 `dist`、`apps/desktop/dist`、`.artifacts/desktop-runtime` 与旧安装包。

输出包含 DMG、ZIP、`release.json` 和 `SHA256SUMS`。脚本验证 App 严格签名与 DMG 完整性；构建失败时保留当前独立目录用于诊断，下一次使用新目录。
